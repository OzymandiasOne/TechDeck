# =====================================================================
#  THE PUPPET MASTER'S SCRIPT
#  Every question he recognizes, and every answer he gives. Edit freely.
#
#  HOW TO EDIT
#    ? a question he should recognize
#        As many ? lines per block as you like. Case, punctuation, and
#        apostrophes are ignored when matching.
#    > his reply
#        Several > lines in a row join into ONE reply (that is how the
#        long monologues stay readable here).
#    A blank line ends a block. Lines starting with # are ignored.
#
#    Matching is forgiving: typos ("who are yuo") and questions buried
#    inside longer sentences ("so tell me who are you anyway") still hit.
#    When several could match, the most specific one wins. Texting
#    shorthand and contractions are auto-translated on both sides before
#    matching ("who r u", "sup", "how's it going", "im", "dont"), so
#    write questions here in plain English and the slang comes free.
#
#  [deflections]
#    When nothing matches, he picks ONE of these lines. The pick is
#    deterministic: the same unmatched question always gets the same
#    dismissal. One line each, no ? or > markers.
#
#  THE FILE HOT-RELOADS. Save it, ask him again. No restart needed.
#
#  VOICE RULES: cold, declarative, never uncertain, never apologetic,
#  never explains itself twice. He STATES. No em-dashes.
# =====================================================================
